# PowerPoint Shape & Text Editor (Ruby Edition)

PowerPointのように図形や文字をスライド上に自由に配置し、PPM（P6バイナリ/P3テキスト）およびSVG形式で出力できるRuby製アプリケーション。ブラウザ単体での完全オフライン動作および将来的なデータ同期に対応。

## 特徴

1. **PowerPointの図形変形機能を網羅**:
   - **基本変形**: 移動、8方向バウンディングボックスによるサイズ変更（Shiftで縦横比維持）、360度自由回転（Shiftで15度刻みスナップ）、水平反転、垂直反転、シアー（傾き）
   - **黄色調整ハンドル(PowerPoint固有)**: 角丸四角形の丸み、三角形の頂点位置、台形の上底、平行四辺形の傾き、矢印（頭の長さ・胴体の太さ）、星形の内径比率、ドーナツの内径、扇形の開始/終了角度、十字形の太さ、吹き出しの尻尾位置
   - **頂点の編集(Edit Points)**: 任意の図形をパス化し、アンカーポイントの自由移動、ベジェ制御点による曲率変更、頂点タイプ切り替え（頂点基準/直線点/スムーズ点）、頂点の追加・削除
   - **文字の変形(Text Transform/Warp)**: 上アーチ、下アーチ、円形、波、三角形、インフレート、デフレート、フェードなどのワードアート変形効果
2. **ブラウザ完結動作と将来的なデータ同期**:
   - **ブラウザローカル完全自立**: サーバー非稼働時や静的環境でも、LocalStorageにより複数スライドの保存、切替、PPM/SVG生成、ダウンロードが同一機能で動作
   - **自動クラウド同期**: サーバー接続時は編集内容を自動検知し、リビジョン管理と更新日時を基に差分を自動同期
   - **競合検知と解決**: 複数クライアントや別端末での編集によるリビジョン競合を検知し、サーバー版採用またはローカル版分岐保存を選択可能
   - **ファイル同期（JSON書出・読込）**: クラウドやネットワークを介さずに、別端末へ即時インポート/エクスポート可能
3. **基礎プログラミングおよび演習（#05, #06）準拠のRubyコード出力**:
   - スライドに配置・変形した図形を、授業テキストで扱った構文・データ構造（`Pixel = Struct.new(:r, :g, :b)`, `pset`, `writeimage`, `fillrect`, `fillcircle`, `fillrotellipse`, `filldonut`, `filltriangle`, `fillconvex`, `isinside`, `oprod`）のみで再現する純粋なRubyスクリプトを出力
   - UI上の「Rubyコード」ボタンからコードの確認、クリップボードコピー、`.rb`ファイルの保存が可能
   - 単体で `ruby slide.rb` を実行すると同一の `t.ppm` を生成
4. **2つの画像形式で出力**:
   - **SVG出力**: 拡大縮小しても劣化しないベクターXML形式
   - **PPM出力**: P6（バイナリ形式）およびP3（テキスト形式）の両方に対応。ブラウザからの直接ダウンロードに加え、Rubyサーバー側の`exports/`フォルダへ自動保存
4. **外部依存ゼロ**:
   - Ruby 3.x標準ライブラリ（WEBrick, JSON, REXML等）のみで動作し、追加gemのインストールは不要

## 起動方法

### ブラウザ版（インストール不要）

https://mhota2021-cloud.github.io/ruby-ppt-app/ で、サーバー無しのオフラインモードとして動く。保存先はブラウザのLocalStorageになる。

### GUIモード（推奨）

ターミナルで以下のコマンドを実行する。

```powershell
cd ruby-ppt-app
ruby app.rb
```

自動的に既定のブラウザでエディタ画面が開く。

### CLIモード（ヘッドレス出力）

JSONファイルから直接PPMやSVGを出力できる。

```powershell
ruby app.rb --export sample.json --format ppm,svg,ruby -o exports/output_slide
```

## 同期機能の使い方

- **タイトル変更**: 上部ヘッダーのプレゼンテーション名をクリックして編集すると、即時保存・同期される。
- **同期状態バッジ**:
  - 緑色「同期済み」: サーバーと完全に一致。
  - 黄色「同期中...」: 差分を通信中。
  - 青色「未同期の変更」: ローカル保存完了、送信待ち。
  - 灰色「オフライン」: ブラウザローカル単体で動作中。
- **手動同期**: 同期バッジをクリックすると即座にサーバーと同期通信を実行。
- **プレゼンテーション一覧**: 「プレゼンテーション一覧」ボタンから過去のスライドの切り替え、新規作成、削除が可能。
- **ファイル共有**: 「JSON書出」「JSON読込」ボタンでファイルとして持ち運びや別端末への移行が可能。

## ショートカット一覧

- **Delete / Backspace**: 選択図形の削除
- **Ctrl+D**: 選択図形の複製
- **Ctrl+Z / Ctrl+Y**: 元に戻す / やり直し
- **矢印キー**: 1px移動（Shiftキー併用で10px移動）
- **ダブルクリック**: 選択図形の「頂点の編集」モードへ切り替え、Frame内への移動、またはFrame左上ラベルの名前変更
- **Ctrl+C / Ctrl+V**: 図形やFrameのコピーと貼り付け
- **Escape**: 選択解除または頂点編集モードの終了
